Новости Гайды Подборки

OpenAI сосредоточилась на более прикладном решении.

В то время как дискуссии о будущем начинающих программистов продолжаются, OpenAI сделала практичный шаг вперёд — научила Codex работать с заранее подготовленными сценариями, которые можно использовать без повторных объяснений.


Codex — это уже не просто инструмент для подсказки кода. OpenAI представляет его как облачного ИИ-агента: он принимает задачу, самостоятельно пишет код, выполняет тестирование и выдает готовый результат. При этом разработчику не обязательно вручную работать через терминал.


Главная сложность подобных агентов всегда заключалась в контексте. Если задача описана недостаточно точно, система может выполнить не то, что ожидалось, или начать запрашивать дополнительные пояснения. Новая библиотека решает эту проблему благодаря набору готовых сценариев — Skills, которые задают понятную структуру работы.


По сути, Skills — это набор инструкций с примерами, который сочетает в себе шаблон запроса и краткое руководство. Каждый сценарий задает конкретный тип задачи: как Codex должен интерпретировать запрос, что учитывать при проверке и в каком виде возвращать результат. Подключение происходит быстро — нужный навык можно активировать прямо через интерфейс.


Библиотека охватывает разные направления разработки. Для iOS и macOS предусмотрен отдельный блок возможностей: Codex способен создавать приложения на SwiftUI с нуля, интегрировать App Intents для Siri и Shortcuts, оптимизировать сложные экраны и запускать проект в iOS Simulator для поиска визуальных ошибок.


Для фронтенд-разработки есть сценарий, в котором агент берет макет или скриншот и преобразует его в адаптивный интерфейс. После генерации выполняются визуальные проверки, чтобы убедиться в корректности результата. Также поддерживается интеграция с Figma: Codex анализирует выбранные фреймы и создает код с учетом структуры дизайна и используемых токенов.


Среди дополнительных сценариев есть и менее очевидные задачи. Например, Codex способен создавать браузерные игры по описанной механике, сразу тестируя их в реальном браузере. Также он может автоматически распределять баг-репорты по приоритетам или преобразовывать сложные технические материалы в понятные структурированные отчеты для обучения.


Отдельно выделяется сценарий Adopt Liquid Glass — он упрощает перенос уже существующего SwiftUI-приложения на новый визуальный стиль iOS 26 с поддержкой Xcode 26. Это особенно полезно сейчас, когда экосистема только адаптируется к обновленным стандартам.


Раньше при передаче задачи Codex разработчику приходилось каждый раз заново объяснять весь контекст — словно вводить нового сотрудника в курс дела. Skills устраняют эту необходимость: агент заранее понимает подход к типовой задаче, знает, что нужно проверить и в каком формате предоставить результат.


Помимо готовых сценариев, OpenAI добавила возможность создавать и сохранять собственные Skills. Это удобно для команд, которые регулярно повторяют одинаковые процессы: достаточно один раз описать сценарий, после чего Codex сможет использовать его как постоянный рабочий инструмент.
